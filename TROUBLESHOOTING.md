# Astra troubleshooting

- Set your latitude and longitude. The default reference location is Greenwich. This is calculated astronomy, not cloud forecasting.
- The canopy is intentionally dim. Increase brightness gradually and use fullscreen_below. It stays transparent.
- Hidden pages and suspension pause drawing. Reduced motion limits updates; lower fps and starMagnitude for less work.

Use the README for settings, dependencies, privacy and sources. For a bug report, include your device, MagicMirror and Node versions, the observed behavior and a minimal configuration with secrets removed. Do not post private feeds, tokens, precise home coordinates or network snapshots.
